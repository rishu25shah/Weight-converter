# Weight Converter

A lightweight command-line utility written in Python to convert weight measurements between kilograms and pounds.

## Features

- Bidirectional conversion between kilograms and pounds
- Simple interactive terminal interface
- Output rounded to one decimal place

## Prerequisites

- Python 3.x installed on your system

## Usage

Run the script using Python:

```bash
python weight_converer.py
```

Follow the prompts to enter:
1. The numeric weight value.
2. The current unit: `K` for kilograms or `P` for pounds.

## Example

```text
Enter the weight: 70
Is your given weight is in kilograms or pounds?(K/P) K
Your weight in pound is: 154.4LPS
```
